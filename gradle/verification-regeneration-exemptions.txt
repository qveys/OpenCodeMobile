# Workflows allowed to pass --write-verification-metadata (SEC-05b, control 3).
#
# One entry per line: the workflow path, whitespace, then the reason it may
# regenerate the dependency pins. A line with no reason is refused by the gate.
#
# The gate only honours an entry whose workflow triggers on `workflow_dispatch`
# and nothing else, so this list cannot be used to let a `pull_request` or `push`
# job rewrite the pins. Adding the flag and a `pull_request` trigger in one pull
# request fails.
#
# This list is deliberately empty: no CI job regenerates the pins. The flag is
# only correct from a machine that reaches BOTH Maven Central and the Gradle
# Plugin Portal, because the two serve different bytes for several plugin marker
# POMs (docs/CI-CD-SECURITY.md §8.1). Pins are regenerated by a developer and
# landed through a normal review.
